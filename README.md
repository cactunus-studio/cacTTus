# cacTTus

Экспериментальный патч для APK TikTok 47.7.1 (SHA-256 `3b68b645a9d6ab69336152c613e644aaaf8d09aa001413518f27b4517be07b0c`). Скрипт подставляет `kz` в трёх найденных вызовах получения страны SIM и сети. Другие способы определения региона сохраняются; доступность сервиса и работа приложения не проверены. Переключатель региона пока не реализован.

GitHub Actions запускается при изменениях в main и вручную. Для автоматического запуска задайте секрет репозитория `CACTTUS_APK_URL` с прямой HTTPS-ссылкой на исходный APK; при ручном запуске ссылку можно передать в `apk_url`. Workflow проверяет файл, распаковывает, патчит, собирает и подписывает APK тестовым ключом. Исходный APK в репозиторий не включён. Сборка сторонним ключом несовместима с подписью оригинального приложения; Android не позволит обновить оригинал поверх установленного приложения. Удаление оригинала может удалить его локальные данные.
