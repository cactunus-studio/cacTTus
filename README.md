# cacTTus 🌵

Экспериментальная модификация TikTok для Android без root. Проект исследует смену региона приложения; текущая версия собрана на основе TikTok 47.7.1.

## Что работает

При включённой подмене патч подставляет выбранную страну (по умолчанию Казахстан, `kz`) в двух найденных вызовах получения страны SIM-карты. Подмена страны сети включается отдельно. Другие способы определения региона, включая IP-адрес и данные аккаунта, могут влиять на результат. Работа ленты и доступность сервиса на устройстве пока не проверены.

## Меню мода

Вход в меню расположен на экране «Настройки и конфиденциальность»: строка «cacTTus · Регион и настройки» внизу экрана. Плавающая кнопка удалена. Пункт открывает отдельную полноэкранную Activity с кнопкой возврата, прокруткой, светлой и тёмной темой и системными акцентными цветами на Android 12+. Диалог меню удалён.

Доступны Казахстан (по умолчанию), США, Германия, Турция, Великобритания и Япония. Выбор сохраняется между запусками. Переключатель «Подмена страны» возвращает исходное определение страны. Подмена страны сети вынесена в отдельный переключатель и по умолчанию отключена: обычно меняется только страна SIM. После изменения настройки перезапустите приложение.

Сборка и подпись APK проверены, но запуск на Android-устройстве, отображение меню и влияние настроек на ленту пока не проверены.

## Установка

Скачайте экспериментальный APK из раздела [Releases](../../releases), перенесите его на Android и установите. Сборка подписана тестовым ключом, поэтому Android не установит её поверх официального TikTok с другой подписью. Перед удалением оригинала сохраните нужные данные: удаление приложения может стереть локальные черновики и настройки.

## Сборка

GitHub Actions запускает сборку при изменениях в `main` и вручную. По умолчанию исходный APK скачивается по предоставленной пользователем публичной ссылке Google Drive, включая подтверждение большого файла. Можно переопределить источник секретом `CACTTUS_APK_URL` или полем `apk_url` при ручном запуске. Доступность исходного файла зависит от владельца ссылки и лимитов Drive.

Сборка принимает только исходный APK с SHA-256:

```text
3b68b645a9d6ab69336152c613e644aaaf8d09aa001413518f27b4517be07b0c
```

Workflow проверяет контрольные суммы исходного файла и инструментов, применяет [патч](/scripts/patch_region.py), собирает APK и подписывает его тестовым ключом. Результат сохраняется как артефакт Actions `cacttus-experimental`; workflow не создаёт релизы. Исходный APK в репозитории не хранится.

## Если не работает поиск

Известно о неработающем поиске в первой экспериментальной сборке. Причина пока не установлена. В новой версии страна сети по умолчанию не подменяется; это диагностическое изменение, а не подтверждённое исправление поиска. Если проблема остаётся, отключите «Подмена страны», полностью перезапустите приложение и сравните результат. Для диагностики нужны точный текст ошибки и версия Android.

## Кеш Actions

Workflow кеширует исходный APK, проверенные инструменты и чистую распаковку до применения патчей через `actions/cache`. Ключ содержит версию схемы, идентификатор исходного APK и версию APKtool. После восстановления повторно проверяются SHA-256 исходного APK и инструментов. Изменяемая рабочая копия создаётся отдельно; патчи не попадают в кеш распаковки. Неизменённые DEX-файлы берутся из оригинала, чтобы не пересобирать их повторно.

## Диагностика меню

Получен отчёт о вылете при открытии настроек на Android 17 / LineageOS 24. В исправлении удалено изменение разметки TikTok и добавлена изоляция ошибок загрузки меню и отложенного UI-callback. Причина вылета без стека исключения не подтверждена. Ошибки мода записываются с тегом `cacTTus`; для диагностики повторного вылета пригодится `adb logcat -b crash -d` (перед отправкой удалите личные данные).

Ошибки меню показываются в окне с кнопкой «Скопировать лог». Неперехваченные Java-ошибки приложения сохраняются в закрытых настройках и показываются при следующем запуске; исходный обработчик падения TikTok сохраняется. Логи не отправляются по сети. Нативные падения, остановку процесса системой и ANR этот обработчик не перехватывает. Исправление конкретного вылета на Android 17 требует проверки на устройстве или стека исключения.

## Экран и перерывы

В меню добавлены отключённые по умолчанию опции:

- **Антивыгорание:** сдвиг содержимого на 2 физических пикселя раз в минуту по четырём направлениям. При уходе с экрана или отключении функции смещение сбрасывается. Это уменьшает неподвижность изображения, но не гарантирует защиту OLED и не заменяет снижение яркости.
- **Перерыв:** напоминание после 20 минут нахождения приложения на переднем плане; фоновое время не учитывается.

Сборка и граничные условия политики проверяются автоматически. Отображение и работу с конкретной прошивкой необходимо проверить на устройстве. Меню пока использует системные Material-виджеты и динамическую палитру, а не библиотеку Material 3. Плеер, фильтры контента и закладки из первоначального списка идей ещё не реализованы.

Подмена страны снова включена по умолчанию: Казахстан остаётся выбранным регионом. Предыдущее принудительное отключение отменено однократной миграцией. Это восстанавливает прежнее поведение подмены, но не гарантирует немедленное обновление серверных рекомендаций. Поиск с включённой подменой пока не исправлен. Миграция срабатывает только один раз; после неё пользователь может отключить подмену вручную.

До загрузки сохранённых настроек возвращается `kz`, как в первоначальной сборке с работающей свежей лентой. После инициализации применяется сохранённый выбор.

## Диагностика поиска

Поиск при включённой подмене страны пока не исправлен. Для установления причины добавлена кнопка «Диагностика поиска»: после пустого результата она показывает разобранные служебные поля ответа (`status_code`, `error_code`, `item_count`, известное значение `search_nil_item` и числовой `text_type`). Запросы, результаты, URL, cookies, токены и произвольный текст сервера не сохраняются. Эти поля могут отсутствовать или иметь значения по умолчанию; они не заменяют трассировку сетевого ответа. Если ответ не зафиксирован, окно прямо сообщает об этом. Результаты поиска и параметры сети этот диагностический патч не изменяет.
