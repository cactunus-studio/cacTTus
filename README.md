# cacTTus 🌵

Экспериментальная модификация TikTok для Android без root. Проект исследует смену региона приложения; текущая версия собрана на основе TikTok 47.7.1.

## Что работает

Патч подставляет выбранную страну (по умолчанию Казахстан, `kz`) в двух найденных вызовах получения страны SIM-карты. Подмена страны сети включается отдельно. Другие способы определения региона, включая IP-адрес и данные аккаунта, могут влиять на результат. Работа ленты и доступность сервиса на устройстве пока не проверены.

## Меню мода

Вход в меню расположен на экране «Настройки и конфиденциальность»: строка «cacTTus · Регион и настройки» внизу экрана. Плавающая кнопка удалена. Меню использует округлые панели, светлую и тёмную тему системы и системные акцентные цвета на Android 12+.

Доступны Казахстан (по умолчанию), США, Германия, Турция, Великобритания и Япония. Выбор сохраняется между запусками. Переключатель «Подмена страны» возвращает исходное определение страны. Подмена страны сети вынесена в отдельный переключатель и по умолчанию отключена: обычно меняется только страна SIM. После изменения настройки перезапустите приложение.

Сборка и подпись APK проверены, но запуск на Android-устройстве, отображение меню и влияние настроек на ленту пока не проверены.

## Установка

Скачайте экспериментальный APK из раздела [Releases](../../releases), перенесите его на Android и установите. Сборка подписана тестовым ключом, поэтому Android не установит её поверх официального TikTok с другой подписью. Перед удалением оригинала сохраните нужные данные: удаление приложения может стереть локальные черновики и настройки.

## Сборка

GitHub Actions запускает сборку при изменениях в `main` и вручную. По умолчанию исходный APK скачивается по предоставленной пользователем публичной ссылке Google Drive, включая подтверждение большого файла. Можно переопределить источник секретом `CACTTUS_APK_URL` или полем `apk_url` при ручном запуске. Доступность исходного файла зависит от владельца ссылки и лимитов Drive.

Сборка принимает только исходный APK с SHA-256:

```text
3b68b645a9d6ab69336152c613e644aaaf8d09aa001413518f27b4517be07b0c
```

Workflow проверяет контрольные суммы исходного файла и инструментов, применяет [патч](/scripts/patch_region.py), собирает APK и подписывает его тестовым ключом. Результат сохраняется как артефакт Actions. Исходный APK в репозитории не хранится.

## Если не работает поиск

Известно о неработающем поиске в первой экспериментальной сборке. Причина пока не установлена. В новой версии страна сети по умолчанию не подменяется; это диагностическое изменение, а не подтверждённое исправление поиска. Если проблема остаётся, отключите «Подмена страны», полностью перезапустите приложение и сравните результат. Для диагностики нужны точный текст ошибки и версия Android.

## Кеш Actions

Workflow кеширует исходный APK, проверенные инструменты и чистую распаковку до применения патчей через `actions/cache`. Ключ содержит версию схемы, идентификатор исходного APK и версию APKtool. После восстановления повторно проверяются SHA-256 исходного APK и инструментов. Изменяемая рабочая копия создаётся отдельно; патчи не попадают в кеш распаковки. Неизменённые DEX-файлы берутся из оригинала, чтобы не пересобирать их повторно.
